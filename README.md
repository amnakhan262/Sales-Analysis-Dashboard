
# 📊 Sales Analysis Dashboard

An end-to-end data analysis project that transforms raw retail 
sales data into a professional interactive Power BI dashboard.

## ✨ What This Project Does
- Loads and explores a real-world retail dataset of 9,994 records
- Cleans and processes raw data using Python and pandas
- Performs Exploratory Data Analysis (EDA) to find key business insights
- Builds a fully interactive Power BI dashboard with multiple visuals

## 📊 Dashboard Features
- **Bar Chart** — Sales by Product Category
- **Line Chart** — Sales trends over time (2014–2017)
- **Donut Chart** — Sales by Customer Segment
- **Map Visual** — Sales by US State with bubble sizing
- **Slicer** — Filter everything by Region instantly

## 🔍 Key Insights Found
- Technology is the highest revenue generating category
- Consumer segment accounts for 50% of total sales
- California and New York are the top performing states
- Sales show consistent growth trend from 2014 to 2017
